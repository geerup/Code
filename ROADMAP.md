# 30-Project Portfolio Roadmap

A deliberate path to a software career in **AI/ML + full-stack**, anchored on
**AI agents/LLM apps** and **games/creative**. Built as a mix of small,
fully-deployed projects plus a few deep flagships — every project shipped live
with CI, tests, and a real README.

## Goals
- Prove I can **ship product** *and* understand the **systems underneath**.
- Weight the work toward **AI agents/LLM apps** and **games/creative**.
- Every project: **live deployment + CI + tests + README + demo**.
- By #30, the GitHub timeline tells one clear growth story.

## Quality bar (every project)
- [ ] README: problem, architecture, tech trade-offs, run steps
- [ ] Tests + GitHub Actions CI (lint/test/build) — green badge
- [ ] Live deployment (URL / static site / released binary) + demo GIF
- [ ] Clean commits on a branch, merged via PR
- [ ] "What I learned / what's next" note

## Expanding to 30
Target mix: **~25 small/medium + ~5 flagships**.

- **AI agents / LLM apps (~12):** RAG assistant, agentic task runner, code-review CLI,
  AI dungeon master*, AI party game*, prompt-eval harness, multi-agent research crew,
  chat-bot integration, semantic search over a personal corpus, AI NPC dialogue engine,
  voice assistant, fine-tune/eval mini-project.
- **Games / creative (~9):** multiplayer mini-game, WASM generative art, procedural map
  generator, physics/particle sandbox, retro clone with a twist, shader gallery,
  level-design tool, leaderboard service, game-jam entry.
- **Systems / infra (~5):** vector search engine, key-value store, mini message queue,
  rate-limiter/load-balancer demo, observability dashboard.
- **Full-stack / glue (~4):** niche social app, real-time data dashboard, auth+billing
  SaaS starter, portfolio index site linking all 30 live demos.

\* = flagship
